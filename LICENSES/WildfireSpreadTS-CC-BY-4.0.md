# WildfireSpreadTS and WSTS+ attribution

This project uses data from the following datasets, both released under the
[Creative Commons Attribution 4.0 International licence (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

- **WildfireSpreadTS (WSTS)**: Gerard, S., Zhao, Y., Sullivan, J. *WildfireSpreadTS: A dataset of multi-modal time
  series for wildfire spread prediction.* NeurIPS 2023 Datasets and Benchmarks Track.
  [doi:10.5281/zenodo.8006177](https://doi.org/10.5281/zenodo.8006177)
- **WSTS+**: Lahrichi, S., Bova, J., Johnson, J., Malof, J. *WSTS+: An extended dataset for time-series wildfire spread
  prediction* (adds the years 2016, 2017, 2022 and 2023). Zenodo record 17584629; described in
  [arXiv:2502.12003](https://arxiv.org/abs/2502.12003).

Changes made: files are converted to a compact array format and normalised for model training.
The datasets are not redistributed in this repository.
